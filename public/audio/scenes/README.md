# Recordings for "It started as a joke"

This folder is empty on purpose: no voice has been recorded yet, and none is generated. The film plays with
subtitles only until recordings are supplied.

To add one: save the file here under the name below (MP3), then add the same name, without `.mp3`, to `RECORDED`
in `src/components/welcome/scenes/scenes.ts`. With "Sound on", it plays as its subtitle starts.

| File | Speaker | Line (from the launch video script) |
|---|---|---|
| `scale-fat.mp3` | Bag | Are you... calling me FAT? |
| `scale-limit.mp3` | Agent | Sir, the bag is over the limit. |
| `scale-host.mp3` | Host | Take it up with her. |
| `toss-ow.mp3` | Bag | OW! ...I felt that in my flip-flops. |

| `hold-hello.mp3` | Bag | Hello? ...Anyone? ...Cool, cool. I'll just be here. |

Record each bag line with its pauses as written; the subtitle timing in `scenes.ts` can then be matched to the take.
