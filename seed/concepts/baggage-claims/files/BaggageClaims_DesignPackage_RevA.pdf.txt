BAGGAGE CLAIMS MK1

Motion-Reactive Comedy Audio Device for Luggage

Package contents: (1) Low-Level Design, (2) Interface Control Document, (3) Assembly Guide.

Companion files: schematic.png, 3d_view.png, BOM_shopping_list.csv

Doc rev A - 2026-11-19 - Prepared for prototype build with Micro Center same-day pickup + Amazon next-day parts.

Product summary. A battery-powered puck (~64 USD prototype BOM, <8 USD at 1k volume) that straps to luggage.
An MPU-6050 IMU feeds a pattern-recognition state machine on an ESP32-S3; detected travel events trigger
context-appropriate comic audio from a DFPlayer Mini through an 8-ohm speaker. Powered by 3x AA alkaline cells -
deliberately NOT lithium - so the device is unrestricted in checked baggage per FAA PackSafe (lithium devices must be
fully off in the hold; alkalines carry no such restriction).

1. Low-Level Design (LLD)

1.1 Architecture

Single-board system, no networking (WiFi/BT radios disabled in firmware to save power and avoid RF certification
scope). Data flow: IMU samples at 100 Hz -> ring buffer (2 s) -> feature extractor (magnitude, jerk, variance,
orientation, periodicity) -> event classifier (rule-based thresholds) -> gag dispatcher -> DFPlayer UART command ->
speaker. A cooldown timer prevents gag spam; a state latch prevents double-triggering one journey event.

1.2 Module functions

RefDes | Module | Function | Design notes
U1 | ESP32-S3 DevKit | Application processor: sampling, classification, state machine, power management, USB-C programming | Deep-sleep 30-60 uA between wake windows; wakes on IMU motion-interrupt or 1 s timer. Radios off.
U2 | GY-521 MPU-6050 | Motion sensing: accel range +/-8g, gyro +/-500 dps, I2C addr 0x68, @400 kHz | MUST be rigidly screwed to mid-plate (no foam!). Mounting compliance destroys jerk signatures. Configured for motion-interrupt output on INT pin.
U3 | DFPlayer Mini | Plays pre-rendered MP3s from FAT32 microSD; hardware decode; 3W class-AB amp; CS pin or BUSY line for playback status | Files numbered 0001.mp3-0128.mp3. 3 folders = 3 voice packs (Family / Salty / New Yorker), selected by S2 long-press.
SPK1 | 8 ohm 3W speaker | Acoustic output, differential drive from U3 SPK_1/SPK_2 | Faces tuned grille in top shell. ~85 dBA @1m - loud enough for terminals, below PA levels.
BT1/S1 | 3x AA + slide switch | 4.5-4.9 V bus into DevKit VIN pin; onboard LDO makes 3.3 V rail | Master power switch = guaranteed zero-activation for cargo-hold compliance if user chooses.
S2 | Tactile button | Short press: volume cycle (50/75/100%). Long press: voice pack swap. 10s hold: factory reset | Debounced in software.
SD1 | microSD | 128 voice clips, ~64 kbps mono MP3, total <150 MB | Naming: /01/0001.mp3 ... voice pack folder /01-/03.

1.3 Pin map

Net | ESP32-S3 pin | Destination | Type | Notes
I2C_SDA | GPIO9 | U2 SDA | Digital 3.3V | 4.7k pull-up (on GY-521)
I2C_SCL | GPIO8 | U2 SCL | Digital 3.3V | 400 kHz fast mode
UART1_TX | GPIO17 | U3 RX via R1 (1k) | Serial 9600 8N1 | 1k series R = DFPlayer noise-immunity best practice
UART1_RX | GPIO16 | U3 TX | Serial 9600 8N1 | Status/ACK frames
BUSY | GPIO4 | U3 BUSY | Digital in | LOW while playing; gates dispatcher
MOTION_INT | GPIO6 | U2 INT | Digital in, wake | Falls out of deep sleep on motion
MODE_BTN | GPIO5 | S2 | Digital in | 10k pull-up, active low
VIN | VIN/5V pin | S1 -> BT1+ | Power 4.5-4.9V | Never battery-power while USB-C inserted
GND | GND | All modules | Power return | Star at battery negative

1.4 Event detection thresholds (tunable constants)

Event | Rule | Threshold / window | Gag example
HARD_IMPACT | Peak |a| > T after free-fall or rest | 8-14g peak, <50ms | 'OW! I felt that in my flip-flops!'
WEIGH_IN | Lift 1.2-2.0 m/s up, hold still, then set down | 3.5-6s stationary at +0.8-1.2m height | 'Are you calling me FAT?'
HANDLE_GRAB | Sustained tilt + steady carry accel RMS | Carry-mode 10-90 s | 'Are you gonna buy me dinner first?'
FREEFALL | |a| < 0.15g | Persist >= 0.28s, then impact | Wilhelm scream

Calibration rig: shake-table not required - a duffel bag + drop tests onto carpet from 0.3/0.6/1.0 m plus a
luggage-carousel video loop tunes T..constants. Log raw IMU to serial CSV during tuning.

1.5 Firmware state machine

States: BOOT -> CALIBRATE (2s gravity vector) -> IDLE(deep sleep, INT wake) -> ACTIVE_SAMPLE -> CLASSIFY ->
DISPATCH (plays clip via U3, BUSY gate) -> COOLDOWN (3s) -> IDLE. Supervisor rules: one gag per event class per
journey-phase; max 6 gags/hour anti-annoyance governor; volume button usable between clips only. Battery <3.3V
pack -> low-battery rasp ("I... hun...ger") once, then brownout-safe sleep.

2. Interface Control Document (ICD)

2.1 Interface inventory

IF# | Name | Type | Ends | Standard/protocol
IF-1 | POWER | Electrical DC | BT1/S1 -> U1 VIN | 4.5-4.9V, 300mA typ, 1.8A audio peak, 60uA sleep
IF-2 | I2C_0 | Serial digital | U1 <-> U2 | I2C, 400kHz, addr 0x68, reg map per InvenSense RM-MPU-6000A
IF-3 | UART1 | Serial digital | U1 <-> U3 | UART 9600 8N1, YX5200 command set (0x7E frame)
IF-4 | AUDIO | Analog speaker | U3 -> SPK1 | Differential PWM, 8 ohm, <=3W
IF-5 | GPIO_INT | Digital | U2 INT -> U1 GPIO6 | Active-high pulse, wake-capable
IF-6 | GPIO_MODE | Digital | S2 -> U1 GPIO5 | Active-low, debounce 30ms
IF-7 | USB-C | User/service | PC <-> U1 | Firmware flash + 115200 baud debug console
IF-8 | MECH | Mechanical | Device -> luggage | 2x Velcro strap, 25mm; optional 3M VHB pad

2.2 IF-3 command subset (U1 -> U3)

Cmd | Hex | Effect
Set volume | 0x06 v (0-30) | Maps volume cycle 50/75/100% -> v=15/23/30
Play folder file | 0x0F f i | f = voice pack (1-3), i = gag index 1-128
Query BUSY | poll GPIO4 | LOW = playing; dispatcher holds queue

2.3 IF-2 register usage (U2)

Register | Addr | Setting | Purpose
ACCEL_CONFIG | 0x1C | +/-8g | Impact dynamic range
GYRO_CONFIG | 0x1B | +/-500 dps | Carousel rotation band
SMPLRT_DIV / DLPF | 0x19/0x1A | 100Hz, 42Hz BW | Anti-alias jerk detection
INT_ENABLE/INT_PIN | 0x38/0x37 | Motion interrupt, open-drain | Sleep wake source
PWR_MGMT_1 | 0x6B | PLL on X gyro | Stable clock, low noise

2.4 Environmental & regulatory interface limits

Checked-bag environment drives the design: -10C to +45C storage (cargo holds), 0-95% RH non-condensing, shocks
to 40g survival (functional spec 14g), IP424 splash ingress via speaker-grille hydrophobic mesh. Power chemistry:
alkaline AA only (no UN38.3 lithium cells) - this is the compliance hinge for checked-bag operation under FAA
PackSafe. Acoustic: <=85 dBA @ 1 m to stay a novelty, not a nuisance. Radios disabled -> no intentional radiator; FCC
Part 15 unintentional-radiator treatment (self-declare; ESP32-S3 module itself is FCC certified).

3. Assembly Guide

Tools: soldering iron + solder, flush cutters, small Phillips, hot glue or M2 kit, multimeter. Time: ~90 min first build.

Step 1 - Print the enclosure.

Print bottom shell + top shell from the 3D model (PETG, 0.2mm, 25% infill, 4 perimeters). Alternative: buy an
80x60x40mm project box and drill a 30mm speaker grille (3mm holes in honeycomb) plus strap slot. Verify strap
passes before wiring.

Step 2 - Carrier board.

Lay out U1 (DevKit), U3 (DFPlayer) on the 5x7cm perfboard with 2.54mm female headers. Solder: GND star at one
corner; U1 VIN trace isolated to S1 input.

Step 3 - Wire per schematic (schematic.png).

# | Connection | Check
3a | BT1+ -> S1 -> U1 VIN; BT1- -> GND star | Meter: open switch = 0V at VIN, closed = ~4.7V
3b | U1 3V3 -> U2 VCC; GND; GPIO8->SCL, GPIO9->SDA | GND NEVER to VCC. MPU-6050 board LED lit when powered
3c | U1 5V -> U3 VCC; GND; GPIO17->R1(1k)->U3 RX; U3 TX->GPIO16; U3 BUSY->GPIO4 | 1k resistor mandatory - kills DFPlayer RX chatter
3d | U3 SPK_1/SPK_2 -> SPK1 (either polarity fine) | Speaker mounted to top shell behind grille w/ hot glue ring
3e | U2 INT -> GPIO6; U2 MUST screw to mid-plate via its 2 holes | Rigid mount = detection accuracy
3f | S2 between GPIO5 and GND + 10k pull-up to 3V3 | Button reachable through shell slot

Step 4 - Load audio.

Format microSD FAT32. Create folders /01 /02 /03 (voice packs). Copy MP3s named 0001.mp3 upward (up to 128 per
folder) - record 10 starter gags yourself, 64kbps mono. Mapping: 0001=impact_1, 0002=impact_2, 0003=weigh,
0004=carry, 0005=freefall, 0006=carousel, 0007=conveyor, 0008=inverted, 0009=idle, 0010=low_batt.

Step 5 - Flash firmware.

Connect USB-C, install Arduino ESP32 core + libraries (Adafruit MPU6050, DFRobotDFPlayerMini). Compile sketch
implementing section 1.5 state machine; open serial monitor at 115200 - expect "CAL OK" then "SLEEP". Wave the
board: serial log should print event classes as thresholds fire.

Step 6 - Integration & acceptance test.

Snap mid-plate+electronics into bottom shell, seat battery pack with foam pad, close top shell, pass strap.
ACCEPTANCE TESTS: (1) drop onto carpet 0.5m -> impact gag within 1s; (2) lift, hold 4s at waist, set down -> weigh
gag; (3) carry 15s -> carry gag; (4) 2h bench idle -> idle gag at wake poll; (5) sleep current < 200 uA one week shelf-life
check.

Field kit: pre-loaded microSD, spare AAs, tiny screwdriver. Compliance card inside shell: "Alkaline AA only. Switch OFF before checking bag
per airline lithium-device handling policy."
